# 🌍 Wanderlust

Wanderlust is a travel/property listing web application built as a learning project while practicing full-stack web development.

The project focuses on understanding how the frontend, Express.js backend, and MongoDB database work together to build a dynamic web application.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* EJS
* MongoDB
* Mongoose
* Bootstrap

## ✨ Features

* View all travel/property listings
* View details of a listing
* Create a new listing
* Edit existing listings
* Delete listings
* Store listing data in MongoDB
* Dynamic pages using EJS
* Server-side rendering with Express.js

## ⚙️ How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/your-username/wanderlust.git
```

### 2. Go to the project folder

```bash
cd wanderlust
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start MongoDB

Make sure MongoDB is installed and running on your system.

### 5. Start the application

```bash
node app.js
```

Or using Nodemon:

```bash
nodemon app.js
```

### 6. Open in browser

```text
http://localhost:8080
```
